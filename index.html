Strata Looper

Professional Multi-Track Audio Looper for Android

Get it on Google Play User Manual
v2.8.0

Features

  • Pro Multi-Track Recording: Record up to 8 independent tracks with unlimited overdub layers.
  • Zero-Latency Feel: Powered by a high-performance C++ audio engine.
  • USB Audio Interface Support: Connect your interface and route inputs (Mono L/R or Stereo) to specific tracks.
  • Creative Effects: Per-track Reverb and Delay to shape your sound.
  • Live Performance Tools: Quantized Mute, Undo/Redo, and Input Monitoring.

Version 2.7.0

New Features

  • Save & load projects: capture the full session — all tracks, overdub layers, per-track FX and chain order, bar counts/offsets, mute/solo states, master gain, and calibration.
  • 5-band graphic EQ per track: 100/400/1k/3k/8kHz peaking bands.
  • Auto-Tune key & scale detection: analyze a recorded track and apply the detected key/scale.

Bug Fixes

  • Fixed effect-order reorder being silently dropped in some cases.

Version 2.6.0

Bug Fixes

  • Fixed bar count reset when main track is cleared with large bar difference between tracks. Improved logic for selecting new main track to prevent bar count overflow and auto-mute tracks that would be truncated.
  • Fixed no-sound in screen recording on some devices.
Version 2.5.0

New Features

  • Auto-Tune Effect (BETA): Real-time pitch correction with YIN pitch detection, 11 scale options, formant preservation, humanize, tolerance, T-Pain mode, and adjustable smoothness.
  • Manual Latency Calibration: Play metronome and record mic simultaneously, then align overlaid waveforms with ±1ms/±10ms buttons in real-time.
  • Multi-Page Track Menu: Menu is swipeable now for accessing multiple pages.
  • New Track Menus: Per-track solo and quantized FX on/off toggle. Tap for instant action, long-press for bar-boundary quantized toggle.
  • Fractional Bar Counts: Track lengths now support 1/8, 1/4, and 1/2 bar values alongside whole bars.
  • Record File Mode Selector: Three-way selector (Audio, Video, Both) replacing the old video record toggle.

Improvements

  • Real-Time Video+Audio Muxing: Encodes video and audio into a single MP4 in real-time on Android 10+, eliminating post-recording muxing.
  • Monitor FX During Recording: Track FX now applied to the monitor signal so what you hear matches playback.
  • FX Latency Compensation: Tracks with latency-inducing FX (AutoTune, Harmonic) now align with other tracks; recording write offset also corrected for overdubs.
  • Single-track clear now preserves bar settings (resets only when all tracks cleared).
  • Unified dialog headers.

Bug Fixes

  • Fixed touch overlay offset and stale strokes on toggle.
Version 2.4.0

New Features

  • Noise Gate: Real-time noise gate with threshold, release, and range controls. Applies to all recordings for cleaner audio capture.
  • Touch Visualization: Redesigned overlay with gesture-aware indicators (tap, long press, drag). "Always show touches" option to display indicators even when not recording.
  • Processing Queue: Video processing status with progress bar in Recording settings.
  • Cache Management: View cache space used and clear cache from Recording settings.
  • Background Processing: Video/audio processing now survives app exit via foreground service.
  • 3-2-1 Countdown: Countdown before screen recording starts.
  • Charging Indicator: Lightning bolt icon in battery indicator when charging.

Improvements

  • Max bar count increased to 32.
  • Video recording quality improved with H264 High profile and higher bitrate.
  • Performance HUD now shows total app memory (PSS), raw CPU usage, and audio xrun counter.
  • Settings and FX dialogs remember last tab and scroll position.

Bug Fixes

  • Fixed track count setting not being remembered across app restarts.
  • Fixed square background appearing behind circular main track ring.
  • Fixed audio crackle on loud recordings (replaced hard-clipping with soft limiter).
Version 2.3.0

New Features

  • Added Window knob to the Harmonic effect (Single and Harmony modes). Adjusts the pitch shifter's grain window size (10-50ms) to trade latency vs artifact smoothness. Smaller values reduce track delay; larger values reduce wrap artifacts.

Bug Fixes

  • Fixed video recording showing no progress indicator or stop button.
  • Fixed harmonic effect delaying the entire track and causing it to fall out of sync with other tracks.
Version 2.2.0

New Features

  • Overdub Low-cut: Optional HPF on incoming overdub signal to prevent low-frequency buildup when stacking layers. Includes auto 8ms fade-in on new layers to eliminate clicks.

Bug Fixes

  • Fixed calibration failing with wired headphones: now falls back to hardware-measured latency when no acoustic echo is detected.

1. Information Collection and Use

Microphone Permission

We request access to your device's Microphone (RECORD_AUDIO).

  • Purpose: To capture audio for the core functionality of the app: recording loops and overdubbing tracks.
  • Data Handling: Audio data is processed locally on your device in real-time. We do not upload your audio recordings to any external server.

Storage / File Access

We may access your device's storage to save and load your audio projects.
